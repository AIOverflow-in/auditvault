1. Background & Problem Statement

Nivyash is a maritime consultancy that conducts a range of audits and inspections for vessel operators globally. Services include Internal Audits & Training, Remote Navigation Audits (VDR-based), Maritime Incident Investigations, Pre-Purchase Inspections, and Ship Recycling Audits.

Prior to this platform, all project coordination happened via email and WeTransfer. Files arrived in multiple formats (audio VDR recordings, video, scanned PDFs, Word documents) with no centralised view of what was active, and clients had no self-service access to their data or reports.

Goal: Build a cloud-based web platform called AuditVault.ai that gives Nivyash full operational visibility and gives each client company (vessel managers) controlled, secure access to only their vessels and projects — replacing email and WeTransfer entirely.

2. What Was Built

A complete full-stack web application was designed, architected, and built from scratch in a single session. The prototype covers the entire Phase 1 scope from the plan.

🔐 Authentication

Email/password login with JWT sessions. Role-based access enforced on every page and API route.

📊 Dashboard

Role-aware overview with stats cards, recent projects feed, and upcoming schedule panel.

🚢 Vessel Registry

Register vessels with IMO number, flag, type, and client company. Full project history per vessel.

📁 Project Management

Create and track audit projects through an 8-stage lifecycle with visual progress tracker.

📎 File Vault

Upload PDFs, Word docs, audio, video, and images per project. Categorised by type. Role-filtered downloads.

🏢 Client Portal

Clients see only their vessels. Final reports visible; internal notes and raw data hidden.

👥 User Management

Full user table across all organisations (admin only). 4 roles with granular permissions.

📝 Internal Notes

Nivyash staff can add internal notes per project. Completely hidden from client users.

10. Development Roadmap

✓

Phase 1 — Core Platform (Complete)

Auth, vessel registry, client orgs, project CRUD, 8-stage lifecycle, file upload, internal notes, role-based access, admin dashboard, audit log.

2

Phase 2 — Client Portal & OneDrive Integration

Microsoft Graph API for file storage to existing OneDrive. Structured folder hierarchy per client/vessel/project. Email notifications on key stage changes (Resend). Client-facing dashboard polish.

3

Phase 3 — Polish & Production

Kanban pipeline with drag-and-drop stage updates. Advanced dashboard filters. Mobile-responsive pass. Bulk CSV import of historical data. Inline PDF preview and audio player for VDR recordings. Deploy to Vercel + Neon PostgreSQL.
